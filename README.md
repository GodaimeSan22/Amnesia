# Amnesia

Simple static site that lets you draw a five-card tarot reading using images placed in the `cards` directory.

Any number of cards can be added and filenames don't matter—the site automatically lists the directory and randomly selects five images for each spread.

## Usage

Open `index.html` in a browser or start a local server:

```bash
npm start
```

## Testing

```bash
npm test
```
